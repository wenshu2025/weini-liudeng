# 初版验收 · 2026-10-25

本轮将原《最后一盏灯》脚本和 `preproduction/为你留灯-v1/level-plan.json` 的路线落实为本地浏览器游戏。没有混入另一个剧院推理项目的设定。

已完成的自动检查：

- 六种旧物调查顺序均进入照片、过桥、告别、通关状态。
- 重复调查不重复计数；记忆播放期间不能并发调查；未齐三段记忆时不可触发城门结尾。
- 中途刷新、重复存档标记和不完整存档恢复到可继续状态。
- 15 个 GLB 的文件头、长度、缓冲区边界与动画片段存在性有效。
- JavaScript 模块语法检查通过。运行所需文件均在本地目录，无 CDN 引用。

已完成的浏览器实机检查：

- 全部 15 个运行模型加载成功，浏览器错误与警告日志为空。
- 从序章出发，使用真实界面自动走近红鞋、食谱、纸花，逐次完成 1/3、2/3、3/3。
- 照片阶段刷新后通过「继续上次的旅程」恢复。
- 三盏灯齐后可自动走过桥，奶奶随行，抵达城门触发告别。
- 告别完成出现终幕；结尾能打开三张完整记忆卡，再返回终幕；重新开始能回到开场。
- 643px 窄屏和 1280px 宽屏实际画面检查，字幕、按钮与物件近景可见。
- 键盘 W 持续一秒，角色 Z 从 1.00 到 3.20，移动速度与设定一致；暂停及重新开始的确认界面可操作。

实际试玩修复：

- 自动指路的目标原在 Z=31.1，停靠容差使玩家可能停在 Z=30.98，无法触发结尾；改为 Z=31.5，复验后顺利触发并通关。
- 城门台阶的模型底座高于平面，模型下移 .43m，让人物不陷入台阶。
- 露娜的 Tripo 行走含约 1.12m 根位移，运行时移除平面根位移，避免动作与路线双重移动。

- 照片与告别阶段改为画面下方字幕，保留三维人物和祭坛可见。
- 露娜终点移到祭坛前，避免走入桌子；相框移到奶奶正面。

边界：未在第二台电脑或手机上实测，触屏控件已实现但尚未真机验收；没有进行现场不知情玩家时长测试。没有配音、口型或祖孙完整回忆动作，当前使用物件近景与字幕表达回忆。通用拾取的精确指尖接触仍可优化。
