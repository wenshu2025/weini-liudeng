# 为你留灯 · 手心里的记忆（本地 v2）

本轮只更新本地游戏；Cloudflare 线上版本没有更新。运行 `python3 launch.py` 或双击「启动游戏.command」。开发预览地址为 http://127.0.0.1:8769/ 。

## 新增人物

- 罗莎，点心摊主：食谱前后及三灯齐全后有不同对白；会回应你选择的糖量。
- 马特奥，广场乐师：能续上一段与记忆数量对应的旋律；结尾引出下一封未寄出的信。
- 阿玛，守灯人：在桥口短距离巡视，靠近时停下交谈；解释旧物、点灯与陪伴。
- 露娜：全程统一为新版小女孩。使用用户提供的慢跑骨骼片段，跑向祭坛；停步、捧照、前伸与摆放通过同一骨架的程序姿态和双臂 IK 完成。她不会在广场与亡灵直接对话。

两个静态 NPC 保留用户模型本身的姿态，没有把整个人平移冒充行走。守灯人使用新增紫裙模型的骨骼动作。

## 三件旧物

1. 红鞋：捧起 → 将左右鞋带端分别拖到中心金圈 → 绕结并系紧。
2. 食谱：翻开 → 在 1–3 勺糖之间选今天的味道 → 拖动木勺画圈，或点击搅拌三次。
3. 纸花：选择纸色 → 拿起 → 沿三条虚线逐道折向中央 → 展开。

每件手作之后播放对应的记忆，再进入点灯仪式。点亮后才计入 1/3、2/3、3/3；不会因为重复点击而多计数。

配方会改变伊莲娜与摊主的对白；鞋结、糖量、纸色会保存在记忆册和存档。选出的纸色会成为最终祭坛上一朵独立的折纸花。食谱没有“错误答案”，继续生活可以有自己的做法。

## 手势

点击「手势体验」→「开启摄像头手势」，由你在浏览器中允许摄像头。建议先把一只手放进镜头中央，看到发光光标后再操作。

- 拇指与食指捏合：捧起旧物；抓住鞋带、木勺或纸边。
- 保持捏合并移动：拖鞋带到金圈、将纸边折向中央。
- 保持捏合并转动手腕：绕出鞋结。
- 在糖量步骤展开手掌向上或向下移动：加一勺或减一勺；再次捏合确认。
- 保持捏合并沿碗边画圈：搅拌。
- 摊开手掌并稍停：展开纸花、把记忆交给桥灯。

鼠标、触屏和按钮能完成全部相同内容，可以中途切换。识别不到手时，互动进度保留，不惩罚、不倒计时。

摄像头只在主动开启后使用，不采集麦克风；识别库、WASM 与模型文件全部存于本地，不上传摄像头画面。「关闭摄像头」会停止所有视频轨道。可先点「检查手势模型（不启用摄像头）」完成一次空白图像推理自检。无需为了玩游戏而允许摄像头。

## 剧情与尾声

- 照片帮助伊莲娜找到回家的方向，取消“家人没摆照片就失去资格”的表达。
- 过桥时伊莲娜会提到你亲手完成的小事，停下时她会等候。
- 通关后可以回到亮灯广场，再听乐师、和摊主聊聊、回看记忆。
- 乐师桌上的信在尾声出现；下一章只是预告，尚未开放。

## 存档与检查

新版使用独立的 v2 本地存档，旧版 v1 进度保留，互不覆盖。更换端口或浏览器不会共享本地存档。

运行 `node test-story.mjs`、`node test-v2.mjs` 与 `node test-gestures.mjs` 检查六种收集顺序、配方保存、阶段对白、手势分类与丢手状态。

摄像头开启与真人手势手感需要用户主动授权后实际试玩；开发侧不自动申请或批准摄像头权限。检查记录以「验收记录-v2.md」为准。
